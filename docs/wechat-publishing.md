# 微信公众号草稿箱发布

WeavePress 当前只对接微信公众号官方 API，将人工审核通过的稿件写入草稿箱，不自动群发，也不使用模拟登录、浏览器自动化或第三方非官方发布协议。

## 发布流程

1. 编辑从已完成采集的文章创建微信稿件。
2. 每次保存使用 `expectedVersion` 乐观锁，并生成一条不可变版本记录；恢复历史版本时也会复制为新版本，不覆盖旧记录。
3. 编辑提交审核，管理员选择通过或退回。
4. 管理员对已通过稿件发起发布任务，服务端在入队前执行微信公众号规则检查。
5. Worker 获取公众号 `access_token`，读取本地或七牛私有素材。
6. 正文图片通过 `media/uploadimg` 上传，并替换稿件中的 `data-weavepress-asset-id` 占位。
7. 封面通过 `material/add_material?type=thumb` 上传。
8. 调用 `draft/add` 创建公众号草稿，并保存返回的 `media_id`。

发布失败会记录稳定错误码、用户可读信息和任务事件。网络、HTTP 429/5xx、微信系统繁忙和 access token 过期允许 Asynq 自动重试；凭据、素材格式和稿件数据错误不会无限重试。管理员可以对最终失败的任务发起手动重试，重复点击不会创建并行任务。

## 配置

```dotenv
WEAVEPRESS_WECHAT_ENABLED=true
WEAVEPRESS_WECHAT_APP_ID=公众号AppID
WEAVEPRESS_WECHAT_APP_SECRET=公众号AppSecret
WEAVEPRESS_WECHAT_API_BASE=https://api.weixin.qq.com
WEAVEPRESS_WECHAT_REQUEST_TIMEOUT=30s
```

生产环境必须使用 HTTPS 微信 API 地址，并在公众号后台配置服务器出口 IP 白名单。`AppSecret` 只进入 API/Worker 进程环境，配置摘要始终脱敏，数据库和前端都不会保存或返回密钥。

## 素材规则

- 封面必填，正文和封面只能引用稿件来源文章下已完成归档的素材。
- 正文图片接受 JPEG、PNG 且最多 1 MiB；封面还可使用 GIF 且最多 10 MiB。WebP 需先转换后才能发布。
- 正文保存清洗后的 HTML，不接受脚本、事件处理器或任意外部图片地址。
- 管理后台预览使用沙箱 iframe 和应用签名素材 URL；真正发布时才换成微信托管图片 URL。

## 发布前检查

稿件工作台通过 `GET /api/drafts/{id}/preflight` 展示当前已保存版本的问题；检查未通过时，服务端不会创建发布任务。首版检查以下规则：

- 标题必填且最多 64 个字符，作者最多 8 个字符，摘要最多 120 个字符。
- 正文必须包含文字或归档图片，不能引用任意外部图片。
- 封面和正文素材必须属于来源文章，并已完成归档。
- 素材格式和大小必须满足上方微信素材规则。

编辑器提供段落、标题、加粗、引用和换行等轻量 HTML 工具，也可以从来源素材图库选择图片插入正文。所有内容保存时仍会经过服务端 HTML 清洗和素材归属校验。

## 已知边界

微信公众号 `draft/add` 没有业务幂等键。如果请求已经被微信接收但响应在网络中丢失，自动重试可能在公众号后台留下重复草稿。发布任务会保留完整事件用于人工核对；正式运营时应在失败重试后检查公众号草稿箱。
